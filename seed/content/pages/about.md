# About NimbusCMS

NimbusCMS is opinionated about architecture and unopinionated about what you build with it. It is deliberately small: a stable core, explicit reusable capabilities, optional plugins, and application-owned business logic.

It exists to be **fast by construction** and **readable by design** — a CMS you can run with an agent and read as a human.

**What it is not.** Nimbus is pre-1.0 and self-hosted. It is not a page builder, an app framework, or a marketplace of a thousand plugins. If you need those, something bigger will serve you better — and that is fine.
